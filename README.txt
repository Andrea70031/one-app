Da iPhone:
1. Apri il repository su github.com.
2. Add file > Upload files.
3. Carica tutti i file sopra.
4. Commit changes.
5. Settings > Pages.
6. Source: Deploy from a branch.
7. Branch: main.
8. Folder: / (root).
9. Save.

Poi apri l'indirizzo GitHub Pages in Safari.
Per installarla: Condividi > Aggiungi alla schermata Home.

La demo include orb animata, listening/thinking/done, input testuale, quick actions e PWA.
